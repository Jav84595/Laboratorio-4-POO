Laboratorio 4 - Polimorfismo

Programa desarrollado en Java para gestionar lotes, bodegas y despachos de la cooperativa AcopioGT, utilizando herencia, polimorfismo e interfaces.

Requisitos:
Java JDK 8 o superior.

Compilacion y ejecucion:

Desde la carpeta principal del proyecto, ejecutar en Git Bash:

```bash
mkdir -p bin
javac -encoding UTF-8 -d bin *.java
java -cp bin Main
```

El programa funciona mediante un menu de consola y utiliza datos almacenados en memoria.
